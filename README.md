## 原生 IP 和住宅 IP，差的到底是什么

这两个词经常被混着用，但在平台风控里是两件事。

原生 IP 回答的是“这个 IP 注册地是不是台湾”。丽萨的台湾原生 IP 线分配台湾 BGP 机房段地址，能解锁台区流媒体，装 Windows 也没问题。但在 MaxMind、IP2Location 这类 IP 归属库里，它的标记是 Datacenter（机房），平台一看就知道这是台服务器。

住宅 IP 回答的是“这个 IP 看起来像不像台湾普通家庭用户”。HiNet 那条线用的是中华电信 HiNet 家宽 PPPoE 拨号 IP，ASN 是 **AS3462**，在同一个数据库里被识别为 Residential。TikTok、Shopee 卖家后台、亚马逊这类对登录环境敏感的平台，对机房段和家宽段的处理方式完全不同：前者容易触发二次验证甚至限流，后者通过率高得多。

> 一句话区分：原生 IP 解决“是不是台湾”的问题，住宅 IP 解决“像不像台湾家庭用户”的问题。两者都能解锁动画疯，但只有住宅 IP 在养号场景里更扛得住。

这也解释了价格差。同样是 1 核 1G，原生 IP 年付 ¥766，住宅线 200Mbps 月付 ¥399，一个月就顶年付的一半多。多出来的钱没有变成更多 CPU 或硬盘，全花在 IP 的获取成本上。

## 大陆访问：先接受它不是 CN2 GIA

丽萨在台湾所有产品线页面上都写了一句话：非大陆直连优化网络，建议通过香港或日本线路中转使用。

公开测评记录里的路由情况大致是这样：电信走 163 普通直连，联通走 AS4837，移动走 CMI；电信回程经上海、广东入口，延迟在 **60–190ms** 之间浮动，晚高峰丢包有波动；联通和移动相对稳，部分节点能压到 **50ms 以内**；整体平均延迟 **100ms 出头**。

这个水平跑 TikTok 发布、电商后台操作、客服聊天没问题，都是非实时业务。但指望它像 CN2 GIA 那样直连打游戏、做实时语音，会失望。

官方给的中转方案是再买一台香港或日本优化线路的机器做前端：大陆流量先到香港/日本，再转发到台湾这台，终端 IP 仍然是台湾住宅 IP，风控视角不受影响。丽萨自家有香港 CMI、CU2、CN2 精品网和日本原生 IP 线，可以在同一个后台一次买齐，也可以用自己的机器。

拿到机器后记得开 **BBR**。这条线不是大陆优化线路，拥塞控制对实际吞吐的影响比在优化线路上明显得多，尤其是中转场景。

- **想直连打游戏或做实时业务的人**。不是 CN2 GIA，晚高峰有波动，中转也只能改善不能消除。
- **只在乎流媒体解锁的人**。原生 IP 线便宜一大截，功能和体验在这个场景里没有差别。

另外，原生 IP VDS 不限流量三档的详细配置官方没有完整公开，如果你对 CPU 和内存有硬性要求（比如要跑重一点的自动化），先确认配置再付款，不要默认它和同带宽的住宅线配置相同。

## 常见问题

**住宅 IP 和原生 IP，哪个更适合 TikTok？**
住宅。TikTok 的风控看的是 IP 归属类型，HiNet 家宽段在库里是 Residential，机房段是 Datacenter。原生 IP 能解锁内容，但不能让账号看起来像本地用户。

**¥766/年 和 ¥399/月 差这么多，多花的钱买到什么？**
买到 IP 属性、不限流量和更大带宽。¥766/年 那档是 1 核 1G、100Mbps、每月 2000GB 双向流量、机房段 IP；¥399/月 那档是 1 核 1G、200Mbps、不限流量、中华电信家宽段 IP。CPU 内存一模一样，差价全在 IP 和流量政策上。

**能装 Windows 吗？**
原生 IP VPS 官方明确支持安装 Windows。住宅线的官方页面描述里也提到支持安装 Windows，但这条线的主流出法是跑代理、浏览器环境或远程桌面，装之前先确认授权和资源够不够，1 核 1G 跑 Windows 会比较紧。

**能换 IP 吗？**
住宅线默认分配动态住宅 IP，目前换 IP 走工单，由客服操作；官方提到后续会上线面板按钮和 Web API 自助切换。原生 IP 线通常是固定 IP，不带换 IP 能力。

**退款怎么算？**
原生 IP VPS 普通套餐 48 小时内可无条件退款、原路退回。HiNet 住宅线和原生 IP VDS 不限流量属特殊产品，48 小时内可退，但只退网站余额。全站统一的“48 小时无理由退款”说法在这三条线上不成立。

**大陆直连能不能用？**
能用，但别期待优化线路的体验。电信 60–190ms 浮动、晚高峰有波动，联通和部分移动节点能到 50ms 以内，平均 100ms 出头。跑后台操作和社媒发布够用，实时业务建议加一台香港或日本机器中转。
